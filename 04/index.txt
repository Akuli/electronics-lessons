## How to think about two-leg components

akuli-note:
    As explained [at the end of the previous lesson](../03#the-important-equation-of-currents),
    whenever some current enters through one leg of a two-leg component, the same current exits out through the other leg.
    Therefore we talk about just one current when discussing two-leg components.

<Akuli> so, here's how to think about all 2-leg components in electronics: you connect some voltage to it, it consumes some current
<Akuli> voltage is like an input, current is what it does when it receives that input
<adder> OK.
<Akuli> how exactly the current is determined depends on the component
<Akuli> but all 2-leg components can be more or less described like this
<adder> OK.
<Akuli> as we learn about various 2-leg components, we will learn different possible relationships between voltage and current
<Akuli> basically, different ways how the components decide how much current to consume

## What is resistance?

<Akuli> the simplest possible is a resistor
<Akuli> current is just a multiplication by a constant
<Akuli> current = voltage * constant

<Akuli> push 2 times harder --> electrons move 2 times faster through it
