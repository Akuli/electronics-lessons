## Combining multiple resistors to handle more power

<Akuli> or, here's a trick that is sometimes useful: combine multiple different resistors, either in series or in parallel
<Akuli> we haven't talked about this yet, but three 1Ω resistors connected to each other correctly is same as one 1/3 Ω resistor
<Akuli> ok?
<adder> Why would chaining up resistors decrease the total resistance?
<Akuli> depends on how you connect them
<Akuli> if you do:  ----resistor1---resistor2---resistor3----
<Akuli> then resistances are added
<Akuli> and you would get 3Ω
<adder> Aaah I see.
<Akuli> if you do:
<Akuli>    ,---resistor1---.
<Akuli>    |               |
<Akuli> ---o---resistor2---o----
<Akuli>    |               | 
<Akuli>    `---resistor3---'
<Akuli> then you get 1/3 ohms
<adder> Right.
<Akuli> i used this exact setup in my stereo amplifier build
<Akuli> in a traditional audio amplifier, you have two output transistors for each speaker
<adder> Cool.
<Akuli> one output transistor increases the speaker's voltage ("pull up"), another to decrease it ("pull down")
<Akuli> inserting a few 0.33Ω resistors makes it easier to tweak those transistors to basically behave nicely when the amplifier is idle
<Akuli> the point is, i needed 0.33Ω resistors, and all the output going to speakers would go through them
<adder> I see.
<Akuli> so by chaining some 1Ω resistors i had, i "made" 0.75W 1/3 Ω resistors
<adder> :)
<Akuli> so that sort of tricks can be used to work around power issues, if you don't want to buy the right thing
