## What is current?

<Akuli> so, let's talk about what is current
<Akuli> to reiterate, voltage is electricity wanting to go from place A to place B, but not necessarily going
<Akuli> current is electrons actually moving somewhere
<adder> Current is, how much charge did get through past the resistance?
<Akuli> you don't necessarily need resistance to have current
<Akuli> it's just how much charge (that is, electrons) is moving
<adder> Sure.
<adder> OK.
<Akuli> a valid unit for current is electrons/second
<Akuli> the problem with that unit is that it is really small
<Akuli> like insanely small
<Akuli> so, you would need huge numbers to describe anything meaningful
<Akuli> ok?
<adder> So we count it as Coloumbs?
<Akuli> a coulomb is a big pile of electrons
<Akuli> a very big pile
<Akuli> so yes, we use coulombs/second
<adder> OK.
<Akuli> but in electronics, you don't usually say coulombs/second, you say amperes, which means the same thing
<adder> OK.
<Akuli> so, an ampere (abbreviated: A) is just a large number of electrons per second
<Akuli> ok?
<adder> OK.
<Akuli> like we discussed with voltage, this is inverted for historical reasons
<Akuli> so a positive amount of amperes from A to B actually means that electrons are traveling from B to A
<Akuli> this will probably become clear when we go actually measure the circuit again
<adder> OK.

## The important equation of currents

<Akuli> i'll mention one more fact about currents that is kinda important here
<Akuli> the important equation for voltages i presented was: V(A -> B) + V(B -> C) = V(A -> C)

akuli-note:
    I explained the "important equation of voltages" [in the first lesson](../01#the-important-equation).

<Akuli> there's a similarly important thing for currents
<Akuli> it goes like this:   sum(currents in) = sum(currents out)
<Akuli> ok?
<Akuli> (i'll explain what this says shortly)
<adder> OK.
<Akuli> this basically says that electrons don't appear or disappear
<Akuli> this is usually presented for intersections of wires, but it actually applies much more broadly than that
<adder> OK.
<Akuli> almost any component you can think of satisfies this, if you consider the currents through all of its legs
<Akuli> resistors, LEDs, capacitors, IC chips (e.g. the 555 timer), a whole computer, anything really
<adder> OK.
<Akuli> the only exception i know is devices that literally shoot electrons
<Akuli> like the CRT tube of an old tv or computer monitor
<adder> OK.
<Akuli> so if you're not messing around with anything like that, this equation holds for any component :)
<Akuli> that's why, in the case of 2-leg components, we talk about just one current
<adder> OK.
<Akuli> whatever goes in through one leg must come out through the other leg
<Akuli> the same current
<adder> OK.
<adder> This is what law?
<Akuli> good question
<Akuli> for intersections of wires, this is kirchhoff's current law
<adder> OK.
<Akuli> in my mind, the more general version that applies to anything other than electron shooting devices and such, is just common sense
<Akuli> if you understand what current is, it should seem obvious
<adder> OK.
